# Streamlit Dashboard

This folder contains a Streamlit dashboard prototype for the final AI quant portfolio model.

## Purpose

The dashboard is designed to make the final model results easier to review visually.

It summarizes:

```text
1. Final model configuration
2. Portfolio-level performance
3. Buy & Hold vs Final ExtraTrees ML comparison
4. Equity curve
5. Asset-level results
6. Interpretation and future extensions
```

## How to Run

From the project root directory:

```bash
streamlit run dashboard/app.py
```

## Required Output Files

The dashboard expects the following files to exist:

```text
backtest/results/final_model_portfolio_summary.csv
backtest/results/final_model_asset_summary.csv
backtest/results/final_model_equity_curves.csv
reports/charts/final_model_robust_assets_equity_curve.png
```

These files are generated by:

```bash
python backtest/final_model_backtest.py
```

## Interpretation

This dashboard presents the final strategy as a risk-controlled portfolio allocation model.

The final ML model did not maximize raw return, but it improved risk-adjusted performance by reducing volatility, maximum drawdown, VaR, and Expected Shortfall while improving Sharpe and Calmar ratios.
